# agentring for iOS

Open [AgentRing.xcodeproj](AgentRing.xcodeproj) in Xcode. See
[the iOS setup and testing guide](../docs/ios.md) for signing, Apple push
credentials, relay setup and hardware validation requirements.

The app is a development preview. The standalone Swift package contains the
protocol/API core and can be checked with `swift test` on macOS.
